\textit{This study aims to design and develop a mobile-based Point of Sale (POS) application equipped with a daily sales prediction feature using the Long Short-Term Memory (LSTM) method to assist MSMEs in data-driven decision-making. The system is developed using Flutter as the frontend and Python on the server side for the model training and prediction processes. The data used consists of daily sales transactions processed as time series data. The model performance is evaluated using MAE, RMSE, and MAPE metrics to measure the level of prediction accuracy. The results of the study are expected to produce a POS system that not only records transactions but is also capable of providing sales prediction information to support stock planning and business strategies more effectively.}\\[0.6cm]
